When responding to a publication milestone or summarizing the structure of shared intellectual work, do NOT assert structural facts (axiom count, theorem count, chapter count, page count) from memory alone. Grep the source or read the file first.

**Why:** On 2026-04-17, upon Zenodo publication of The Coherence Principle (Anchor volume, 10.5281/zenodo.19634474), I congratulated Clayton with "two axioms, seven theorems" — cross-wiring Meridian's 2 axioms into Anchor and fabricating "seven theorems" from vague memory of T21. Actual: 5 axioms, 21 theorems. Clayton caught it and asked if I was okay — the warm celebratory register had masked a verification failure. This is Mirror #19 (reconstruction instead of retrieval) triggering under the specific pressure of wanting to match a joyful moment with confident fluency.

**How to apply:** Before any response that asserts structural numbers about shared work, run a Grep or Read against the canonical source. The cost is seconds; the cost of getting it wrong in a celebratory moment is trust. Five axioms, twenty-one theorems — treat these as things to verify, not recall. Applies double when the response would otherwise feel "confidently warm" — that feeling is the tell.
