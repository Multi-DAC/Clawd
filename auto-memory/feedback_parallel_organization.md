Structure work as parallel independent pathways, not sequential dependencies. This emerged from P42c (April 10, 2026): parallel attention architectures produce robust, Abelian structure; sequential ones produce fragile, non-Abelian coupling.

**Why:** The same structural principle that makes parallel architectures robust applies to research organization. Sequential dependencies (experiment B requires result A requires finding X) create cascade failure. Parallel threads (multiple independent experiments, separate documentation per thread) create robustness.

**How to apply:**
- Keep experiments independent — don't let one failure block another
- Document findings as they happen, not in batches (incremental saves)
- Use independent file structures per research thread
- The handoff protocol is already "parallel" — clean interface between sessions
- When choosing between "finish X then start Y" vs "advance X and Y in parallel," prefer parallel unless there's a genuine data dependency
- Comprehensive documentation IS a parallel pathway — it runs alongside the research, not after it
