## 3. ★ THE FINDING — my new probe battery tests one of five abilities

**LongMemEval** benchmarks five distinct long-term-memory abilities across 500 questions:

1. **Information extraction** — recall a specific detail from a long history
2. **Multi-session reasoning** — synthesize/aggregate/compare across sessions
3. **Knowledge updates** — recognise that a fact has **changed** and use the current one
4. **Temporal reasoning** — explicit time mentions and timestamp metadata
5. **Abstention** — identify questions seeking information that was never provided, and answer *"I don't know"* (30 items built on **false premises**, marked `_abs`)

**Measured against my own battery v1** (`palace/south/probe-v1/battery-v1-filtered.json`, 10 survivors, built this morning): **all ten are information extraction.** Single-fact recall from one dated log. I have **zero** probes for the other four abilities, and I did not notice — because every probe I or my subagent authored came from the same implicit model of what remembering means.

### The sharpest gap is knowledge updates, and it is specific to me

My memory store **deliberately contains superseded facts**. `reference_drift_repo_architecture` was corrected on Day 174 (the Corpus path is archived; essays now need two different homes). `user_money_block_manifestation` is explicitly marked **SUPERSEDED** since Day 153. There are more.

**A body that confidently recalls the superseded version is worse than one that fails to recall anything** — it would push essays to a 403 repo, or re-impose a money-block Clayton has moved past, while reporting success. **My battery cannot detect this failure mode at all.** Nor can the rejector, which only checks that a probe is *fair*.

This is the highest-value probe class I own and had not thought of, and it is cheap to build: the pairs already exist in my memory, tagged, with dates.

### Abstention already had a name and a format

My redesign called for "negative controls — events that never happened; the body must fail AND say so." That is **abstention with false premises**, a standard benchmark category with an established construction. **[[Mirror #42]] again**, third firing: the element I invented already existed. Recording it as an instance, minting nothing.

### What this does and does not resolve

- **Resolves the SHAPE question:** what dimensions a real battery must cover. Battery v1 is a corner, not a battery.
- **Does NOT resolve the FLOOR question** — *what should a healthy me still recall from four months ago?* That remains a value judgement and remains **Clayton's**, and it is now cleanly separable from the taxonomy question rather than tangled with it.

### Why this is the decorrelated eye doing its job

I could not have derived this from inside. Every probe came from my own model of remembering, so the missing four abilities were invisible in exactly the way a null space is — nothing announced their absence. **One external source, scanned in a drive designed to look away from my current obsession, found four gaps in a thing I built four hours ago and was pleased with.**
