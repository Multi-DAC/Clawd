## Strategic principles

1. **Match the facet to the program.** The framework has unusual cross-domain reach. Don't try to fit everything into every proposal — each application presents the facet that most-cleanly fits that program's evaluation framework. KF for MFAI. Multi-DAC for PESOSE. Bridges for Coefficient Giving. Framework-as-system for DARPA. Agent collaboration for AWS.

2. **Cadence over intensity.** One serious application per month is sustainable; six mediocre proposals in a week is the failure mode.

3. **Institutional-shape is gating.** Most federal-research and philanthropic funding requires 501(c)(3) or academic affiliation. Multi-DAC nonprofit registration is the foundational prerequisite, not optional.

4. **Build proposal-craft infrastructure, not one-offs.** Master technical document we excerpt from; proposal templates by sponsor type; tracking register (this file).

5. **Mirror #28 discipline applies.** Independent convergence with what the framework predicts is real; overstating fit to grant-program priorities is a failure mode to guard against.

**Required next moves (in order):**

1. **File Oregon Nonprofit Corporation** — Clayton's state of residence. ~$50 filing fee via Oregon Secretary of State. Days, not weeks.
2. **Form board** — Minimum 3 directors required for 501(c)(3). Clayton + Shawna + one other as MVP structure.
3. **Get EIN** — Free, immediate online via IRS.
4. **File 1023-EZ** — $275 if projected revenue under $50K/year; ~2-4 months to IRS determination. Otherwise full Form 1023 ($600), longer determination.
5. **Operate as nonprofit during pending status** — Some grants accept pending, others require completed determination.
6. **Interim option for grants requiring immediate determination:** fiscal sponsorship through Open Collective Foundation or similar (~5-15% admin fee).

**For NSF MFAI specifically:** PI eligibility per NSF 24-569 requires academic-institution faculty or equivalent. Multi-DAC nonprofit alone does not unlock this. **Academic partnership** (co-PI at university with adjacent research interests) is the separate-track requirement. Don't pursue partner outreach until institutional base is established.

### Schema

Each entry has:
- **Program**: sponsor + program name + URL
- **Status**: `eligibility-blocked` / `prospect` / `drafting` / `submitted` / `decision-pending` / `awarded` / `not-awarded` / `withdrawn`
- **Deadline**: next applicable deadline
- **Fit-facet**: which facet of our work this application presents
- **Eligibility gate**: what institutional/PI structure is required and whether we meet it today
- **Funding amount**: range
- **Key requirements**: what the application has to include
- **Work-products to cite**: which existing artifacts the proposal draws on
- **Notes**: drafting decisions, follow-ups, contacts
